# Ruta

App para aprender idiomas, sobre todo inglés: mapa de categorías, lecciones, vocabulario, pruebas, conversación y un panel para editar el contenido.

```bash
npm install
npm run dev
```

La app queda en http://localhost:8080. El progreso del alumno se guarda en el navegador. El contenido (categorías, lecciones, preguntas) vive en la base de la app.
